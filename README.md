# J&J Distribuição - Landing Page & Catálogo Digital

Landing Page profissional de alta conversão e catálogo de produtos para a **J&J Distribuição**, distribuidora especializada em insumos para acabamento gráfico, tintas especiais, químicos e suprimentos para comunicação visual.

## 🚀 Funcionalidades

- **Design Responsivo & Moderno**: Layout otimizado para desktop, tablet e dispositivos móveis.
- **Catálogo de Produtos com Filtro Interativo**:
  - Tintas & Vernizes UV/Convencional
  - Solventes & Químicos
  - Filmes de Laminação (BOPP, Holográficos, Soft Touch)
  - Blanquetas & Acessórios
- **Captura Inteligente de Leads**:
  - Formulário com tracking automático de origem, data/hora e metadados.
  - Integração com WhatsApp direto com mensagem pré-formatada do produto solicitado.
  - Endpoints REST para captação e listagem de orçamentos.
- **Seções Institucionais Completas**:
  - Hero com chamadas de alto impacto (CTA)
  - Vantagens e diferenciais competitivos
  - Galeria de produtos e soluções
  - Perguntas frequentes (FAQ)
  - Formulário de cotação rápida e rodapé institucional

## 💻 Tecnologias

- **Frontend**: HTML5 Semântico, CSS3 Moderno (Variáveis, Flexbox, Grid), JavaScript ES6+
- **Backend / Servidor Local**: Node.js (`server.js`) com persistência de leads em JSON
- **Ícones & Estilos**: Lucide Icons & Google Fonts (Inter)

## 🛠️ Como Executar Localmente

1. **Pré-requisito**: Ter o [Node.js](https://nodejs.org/) instalado.
2. Inicie o servidor local:
   ```bash
   node server.js
   ```
3. Acesse a aplicação no seu navegador:
   ```
   http://localhost:3000
   ```
   Ou acesse a API de leads capturados em:
   ```
   http://localhost:3000/api/leads
   ```
